> **In short:**
> 1. Collaboration tools cover communication, project management and document sharing.
> 2. All-in-one suites bring several functions together, at the cost of less specialisation.
> 3. Usage rules (which tool for what) matter as much as the choice of tool.
> 4. Access rights must be managed carefully, especially for sensitive documents.

## The main categories of collaboration tools

**Collaboration tools** let a team communicate, share documents and track progress, whether it works in the same office or remotely.

| Category | Main use |
|---|---|
| Instant messaging | Quick exchanges by channel or team |
| Video conferencing | Remote meetings and screen sharing |
| Project management | Tasks, deadlines, owners |
| Shared documents | Co-writing and version tracking |
| Online storage | Access to files from any device |

## All-in-one suite or specialised tools

An all-in-one suite simplifies account and access management. Specialised tools often offer more advanced features in their field. Either way, connections between tools make it possible to [automate repetitive tasks]({{< relref "automate-repetitive-tasks.md" >}}), such as creating a task from a message.

## Good usage practices

- Define where discussions happen, where documents are stored and where tasks are tracked.
- Limit access rights to the people concerned, especially for documents from [payroll software]({{< relref "payroll-software-key-features.md" >}}).
- Check where data is stored: the topic ties in with [web hosting]({{< relref "shared-hosting-vps-cloud.md" >}}) and the cloud.

## Frequently asked questions

<details>
<summary>What are the main collaboration tools in a business?</summary>

The main categories are instant messaging, video conferencing, project management, shared document editing and online storage. Some suites bring several of these functions together in a single environment.

</details>

<details>
<summary>How do you choose a project management tool?</summary>

Start from the way the team works: task lists, column boards, timeline charts. Ease of use, integrations with existing tools and access rights management are then decisive.

</details>

<details>
<summary>How do you avoid tool sprawl?</summary>

By defining a clear purpose for each tool (where to discuss, where to store documents, where to track tasks) and checking whether an existing tool already covers a need before adding a new one.

</details>
