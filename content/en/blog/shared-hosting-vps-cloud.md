> **In short:**
> 1. Shared hosting splits one server between several websites and suits simple projects.
> 2. A VPS reserves resources on a virtual server, with more control but more management.
> 3. A dedicated server gives a single customer an entire machine.
> 4. The cloud lets capacity be adjusted to the load.

## The main types of web hosting

**Web hosting** is the service that stores a website's files and makes it available on the internet. Several options exist, which differ in the level of reserved resources and how much management is left to the customer.

| Option | Principle | For which project | Technical management |
|---|---|---|---|
| Shared | Several websites on the same server | Brochure site, blog | Handled by the host |
| VPS | Virtual server with reserved resources | Steady-traffic website, applications | Often the customer's job |
| Dedicated | A whole machine for one customer | Demanding projects | The customer's job, unless managed |
| Cloud | Adjustable capacity on a distributed infrastructure | Variable traffic, applications | Depends on the service |

## Criteria for choosing

- **Expected traffic** and how it will grow.
- **Available skills** to administer a server.
- **Data location**, which matters for some activities.
- **Backups** offered and how often they run.
- **Support** and its opening hours.

## Security and operations

A website's security depends partly on the host and partly on its administrator: [cybersecurity best practices]({{< relref "small-business-cybersecurity-best-practices.md" >}}) remain essential. A server can also be used to [automate repetitive tasks]({{< relref "automate-repetitive-tasks.md" >}}) through scheduled scripts, and online [collaboration tools]({{< relref "team-collaboration-tools.md" >}}) themselves run on cloud infrastructure.

## Frequently asked questions

<details>
<summary>What is the difference between shared hosting, VPS and cloud?</summary>

With shared hosting, several websites share the resources of the same server. A VPS is a virtual server with reserved resources. Cloud hosting spreads the website over an infrastructure whose capacity can be adjusted as needed. A dedicated server, finally, reserves an entire machine for a single customer.

</details>

<details>
<summary>Which hosting should you choose for a brochure website?</summary>

For a brochure website or a blog with moderate traffic, shared hosting is often enough. It is simple to manage and the host takes care of server maintenance.

</details>

<details>
<summary>Do you need technical skills to manage a VPS?</summary>

Yes, in general. Unless the offer is managed, system administration, updates and VPS security are the customer's responsibility.

</details>
